01 / About

不只是准度，
是把每一次击打
变成「PURRFECT」。

猫二杯是一场面向校园与社区音游玩家的民间线上比赛。我们想做的不是又一张冷冰冰的榜单，而是一个让同好认真打歌、互相认识、玩得尽兴的周末。

比赛设 Phigros 与 Phira 两个项目，采用线上预选与决赛。没有复杂的门槛，也不看你的设备有多贵——只看你愿不愿意为一次 Perfect 反复重来。

这大概就是「STRIVE」的意思：反复尝试，直到接近完美。至于「2」和「PURRFFECT」，是我们夹带的一点私货。

猫二杯赛事组 / 2026

STRIVE 是反复尝试，「2」是 to，PURRFFECT 是猫式的完美。名字是一个不太好笑的谐音梗，但认真是真的。

02 / Projects

两个项目，
同一种执着。

Phigros 与 Phira，两条不同的读谱路径，同一个目标：在正确的时机，按下正确的键。

Project 01 / Mobile 单人赛

Phigros

iOS · Android / 指定曲池 / 线上

在判定线与音符之间寻找属于自己的节奏。预选赛以指定曲目成绩排名，决赛采用直播对抗。设备不限，但每一次击打都要经得起回放。

指定曲池·成绩提交·直播决赛
Project 02 / Multi-platform 单人赛

Phira

多平台 / 指定谱池 / 线上

社区谱面的无限可能。预选与决赛将围绕指定谱面展开，考验的不只是准度，还有读谱、稳定性和临场判断。禁止修改谱面，也禁止小看任何一张自制谱。

社区谱面·指定谱池·直播决赛
